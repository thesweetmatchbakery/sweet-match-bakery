# Sweet Match Bakery — Android Build

This repository builds the Sweet Match Bakery Android app using GitHub Actions.
No Android Studio needed — everything builds in the cloud.

## How to get your .aab file

1. Push this repo to GitHub (or it's already there)
2. Go to the **Actions** tab at the top of the repository page
3. Click on the latest workflow run (it starts automatically on push)
4. Wait 5-10 minutes for the build to complete (green checkmark)
5. Scroll down to **Artifacts** and download **sweet-match-bakery-release**
6. Unzip it — inside is `app-release.aab`
7. Upload that file to Google Play Console
